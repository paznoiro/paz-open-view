zap-open-view

Viewers for file formats whose only browser readers are copyleft (GPL). Each one is a page of its own, loaded by Peek in a frame when you open a file of that type. Your file is handed to the page in your browser and is not uploaded anywhere.

Viewers

  • DWG — AutoCAD drawings, read with LibreDWG (GPL-3.0) and drawn with MLightCAD (MIT).
